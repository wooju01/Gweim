# 캠페인 시뮬레이션 · 50캠페인 × 원정 20번
시작 금화 120 · 시작 짐 5개 · 깨우기 포함 · 필요 경험치 15/75/170 · 단련 40+10×횟수 · 상점 재료 계열 25·파편 30 (원정마다 종류별 3개)
층: 파티 평균 단계 내림 + 1 (최대 3층) · 수입 = 금화 + 유물 판매가 (유실물·재료는 팔지 않는다)
지출 순서: 물자 → 시설(의무실 → 가방 → 훈련장 → 위령비, 숙소 3칸) → 생존 장신구 → (재료 구매) 해금·조립 → (재료 구매) 강화 → 직업 장신구 → 단련 → 승급
