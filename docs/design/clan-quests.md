# Ashen Company — 시간 · 비용 · 숙소/클랜 · 의뢰 (2026-11-21 받음)

## 원칙
- 금액, 일수, 확률은 전부 data 상수(밸런스 때 조정)
- 판정은 코드, 대사·결과 보고는 AI

## 1. 시간 (day)
- `state.day: number`. 하루는 던전에서만 흐름
- 던전 소요 일수 = 도달한 층수(1층 1일, 2층 2일, 3층 3일, 4층 4일). 중간에 후퇴하면 그때까지 간 층수만큼
- 마을 시설 이용은 시간이 들지 않음. 숙소 잠자기 없음
- 던전 귀환 시 처리 순서(`onReturnToVillage`):
  1. 던전 보상 지급
  2. day 증가
  3. 파견 의뢰 일수 진행, 끝난 의뢰 결과 처리
  4. 정산: 지난 정산 이후 7일 경계를 넘은 횟수만큼 클랜 유지비 차감
  5. 파티 전원 체력 완전 회복
  6. 대화 횟수 2로 초기화
  7. 상점·게시판 갱신

## 2. 비용
- 용병(`kind: "merc"`): 던전 출발할 때마다 고용비(기존 로직 유지)
- 클랜원(`kind: "member"`): 고용비 없음
- 클랜 유지비(7일마다): `base + memberCount * perMember + facilityCost` (perMember는 용병 고용비보다 훨씬 싸게)
- 돈이 모자랄 때: `arrearsWeeks` 카운트. 1주 연체: 클랜원 전원 호감 하락 / 2주 연체: 호감이 가장 낮은 클랜원부터 탈퇴 / 다 갚으면 0

## 3. 숙소 → 클랜 본부
- `state.home: "inn" | "clanHall"`
- 클랜 창설 조건: 가입 의사가 있는 용병 8명. 가입 제안 조건: 호감 신뢰 이상. 수락 여부: 호감 + 성격 태그로 판정, 대사는 AI
- 창설하면 home을 clanHall로, 가입한 용병의 kind를 member로
- 1:1 대화(AI): 귀환할 때마다 2명까지 (`talksLeft`)
- 일상 이벤트: 귀환 시 일정 확률로 용병 둘의 짧은 장면(AI). 관계 수치는 저장하지 않음

## 4. 의뢰 (게시판·주점)
```ts
type Quest =
  | { kind: "direct"; id; title; dungeonId; objective: Objective; reward: Reward; }
  | { kind: "dispatch"; id; title; days: number; difficulty: number;
      recommendedGrade: Grade; risk: "low" | "mid" | "high";
      reward: Reward; likedBy?: PersonalityTag[]; dislikedBy?: PersonalityTag[]; };
type Objective =
  | { type: "killBoss"; monsterId: string }
  | { type: "killElite"; monsterId: string; count: number }
  | { type: "collect"; itemId: string; count: number };
```
- 직접 의뢰: 파티가 던전에서 목표 달성. 진행 중 달성 여부 추적, 귀환 시 보상 추가
- 파견 의뢰: 클랜원만(용병 불가), 플레이어는 안 감. `busyUntilDay`까지 편성 불가. 끝나면 코드가 판정(성공/실패/부상/사망, 근거: 등급·스탯 합 vs difficulty, 사망은 영구). 호감: 성공 +, 실패 -, 동료 사망 크게 -, likedBy/dislikedBy ±. 결과 보고는 AI가 짧은 이야기로(결과는 못 바꿈). UI: 위험도와 예상 일수 표시

# 구현하면서 정한 것 (2026-11-21) — 확인 필요
- **용병 보수 시점**: 스펙은 "던전 출발할 때마다(기존 로직 유지)"인데, 기존 로직은 **원정에서 돌아올 때 함께 간 용병에게** 준다. "기존 로직 유지"를 따라 그대로 두었다.
- **고용 한도**: 예전에는 고용 4명 = 파티 4명이라 "가입 의사 8명"이 불가능했다. 고용 한도를 따로 12명(`ROSTER_LIMIT`)으로 두고 원정 파티는 4명 그대로.
- **유지비**: 숙소 시절에는 없다. 클랜 본부: 기본 20 + 클랜원 1명당 2 (용병 보수는 원정마다 3~24). 창설한 날부터 7일 주기.
- **연체**: 못 낸 만큼 빚(`clanDebt`)으로 쌓고 다음 정산에 같이 낸다. 1주 연체부터 클랜원 전원 호감 -5, 2주부터 정산마다 호감이 가장 낮은 클랜원 한 명이 떠난다. 다 갚으면 0.
- **가입 제안**: 호감 75(신뢰) 이상. 수락 확률 = 0.5 + 호감 1당 0.02 + 성격·배경 보정 (명예 +0.2, 다정 +0.15 … 편집증·냉소 -0.15, 떠돌이 배경 -0.2). 거절당하면 다음 귀환까지 다시 못 청한다. 클랜이 이미 있으면 받아들이는 즉시 클랜원.
- **1:1 대화**: 숙소(클랜 본부)에서 귀환마다 2명. 던전 휴식 대화와 같은 규칙(호감만 움직인다, 한 번 답하면 끝).
- **일상 장면**: 귀환 때 40% 확률로 고용한 용병 둘. AI가 3~5문장으로 쓴다.
- **게시판**: 귀환마다 직접 3 + 파견 3을 새로 붙인다(받아 둔 것·나가 있는 것은 빼고). 직접 의뢰는 동시에 3개까지. 기한은 없다.
- **직접 의뢰 판정**: 이번 원정에서 쓰러뜨린 몬스터(정예는 따로 셈)와, 돌아온 뒤 창고의 유실물로 본다. 수집 의뢰는 완료할 때 그 유실물을 낸다. 전멸하면 완료되지 않는다(의뢰는 남는다).
- **파견 판정**: 힘 = Σ(등급 점수 동15·은30·금50… + 쌓인 스탯 합). 성공 확률 = 0.6 + 0.5 × (힘/난이도 − 1), 5~95%. 사람마다 사망(위험도 낮음 1%·보통 4%·높음 10%)·부상(10·20·30%)을 굴리고, 힘이 모자랄수록 커진다. 성공하면 사망 확률 절반. 부상은 3일 더 쉰다. 호감: 성공 +5, 실패 -3, 동료 사망마다 -10, 좋아하는 의뢰 +3, 싫어하는 의뢰 -3.
- **파견 보고 AI**: 결과(성공·실패, 사람마다 무사·부상·사망)를 넘기고 이야기만 쓰게 한다. 결과는 바꾸지 못한다.
- **체력 회복**: 원정은 원래 언제나 가득 찬 체력으로 시작해서 따로 할 일이 없었다.
