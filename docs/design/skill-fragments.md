# Ashen Company — 직업·스킬 조각 시스템 업데이트

## 원칙
- 규칙과 숫자는 코드, 말은 AI. 수치는 전부 data 파일에 두고 나중에 밸런스로 조정한다(하드코딩 금지).
- 스킬은 `{ main: FragmentId, subs: FragmentId[] }`로 저장하고, 효과는 효과 조각을 합쳐 계산한다.
- 이번 작업은 데이터 구조 + 규칙 검증 + 전투 엔진 연결까지. 상한 계산식은 지금은 단순 합산 후 clamp.

## 1. 등급 · 직업 단계
- 등급: 동 → 은 → 금 → 미스릴 → 다이아 → 성휘. 등급마다 3단계(3→2→1), 총 18단계.
- 단계 오름 = 레벨업. 1단계에서 다음 등급으로 = 승급.
- 직업 단계:
  - 동·은: 1차(기본 직업)
  - 금: 2차 전직(두 갈래 중 선택), 궁극기 칸 열림
  - 미스릴: 새 궁극기 획득(가진 궁극기 중 골라 장착)
  - 다이아: 3차
  - 성휘: 4차 최종 직업 + AI가 이명 생성
- 2차·3차 이름은 종족 공통, 4차만 종족별. 표시 이름에 부제 없음.
- 스킬 칸: 일반 4 + 궁극기 1 = 5칸
- 레벨업: 직업 성장표대로 스탯 +3(자동) + 단련장에서 +3(플레이어 배분)

## 2. 조각 규칙
- 스킬 = 메인 조각 1 + 부 조각 0~N
- 부 조각 최대 개수: 동 1개, 은 이상 2개 ← 장착/조합 시 검증
- 메인 조각은 레벨 없음. 부 조각은 Lv1~3(강화 100% 성공)
- 한 스킬 안 부 조각 효과 상한(효과 종류별):
  - 퍼센트 효과 합 ≤ 25%
  - 치명 확률 ≤ 30%
  - 고정 피해 합 ≤ 15
- 조각 풀: 직업마다 공통 메인 4 + 공통 부 4 + 종족 전용 메인 1 + 부 1
- 용병은 공통 조각 + 자기 종족 전용 조각만 사용 가능
- 조각 해금은 전수관에서 유실물로(기존 설계 유지)

## 4. 종족 전용 조각 (메인 / 부, 부는 Lv1→Lv3)
### 기사 (오러는 인간 전용으로 변경, 기존 공통 오러 제거)
- 공통 메인: 검격 1.0배 대기0 / 방벽 2턴 방어+3 대기1 / 결투 신청(적 하나 2턴 기사만 공격, 그 적에게 받는 피해 -2) 대기2 / 돌진 베기 1.2배 대기1
- 공통 부: 휩쓸기(전체, ×0.6) / 투지(준 피해 30% 회복, 위력-10%) / 기사도(옆 아군 보호막3, 대기+1) / 연격(2회, ×0.6씩)
- 인간: 오러 블레이드 1.0배 + 그 공격만 방어 20% 무시, 대기1 / 오러 고정+2→Lv3 +5, 대가 없음
- 엘프: 정령 검격 1.0배 + 마법 0.3배, 대기1 / 바람 정령 사용 후 1턴 회피+15%, 위력-10%
- 드워프: 룬 새김 1.1배 + 대상 방어-2(3턴), 대기1 / 보호의 룬 사용 후 2턴 방어+2, 대기+1
- 궁극기: 기사의 맹세(적 전체 1.5배 + 아군 전체 2턴 방어+2)
- 루트: 세이버→소드마스터→4차(인간 소드 세인트/드워프 룬 팔라딘/엘프 정령 기사), 다크 세이버→데스나이트→4차(인간 데스 로드/드워프 혈룬 기사/엘프 그림자 기사)

### 가디언 (전부 방어형, 반사·반격 위력은 체력 기준)
- 공통 메인: 수호 선언(2턴, 적마다 확률로 가디언 공격) / 감싸기(아군 하나 2턴 대신 맞음) / 방패 강타(힘 0.8배 + 힘 비례 기절 확률) / 철벽(2턴 방어 증가)
- 공통 부: 견고(지속+1턴, 대기+1) / 가시 방패(반사, 위력-10%) / 수호막(보호막4, 대기+1) / 결의(작은 방어 증가, 위력-10%)
- 인간: 수호의 깃발 2턴 아군 전체 방어+1, 대기2 / 굳은 의지 받는 피해 -5%→15%, 대가 없음
- 드워프: 방벽의 룬 2턴 자기 방어+3 + 기절 저항+40%, 대기2 / 대지의 룬 대상 2턴 방어+1, 대기+1
- 바바리안: 버티는 함성 2턴 매 턴 최대체력 5% 회복 + 어그로 증가, 대기2 / 문신의 맹세 다음 받는 피해 -10%→20%, 위력-10%
- 궁극기: 최후의 보루(무조건 선턴, 1턴 아군 피해 전부 대신 + 체력 비례 확정 반격)
- 성장: 체력2 방어1

### 대검사
- 인간: 검기 날리기 1.0배+고정3, 대기1 / 정확한 자세 치명+10%→20%
- 드워프: 룬 각인 대검 1.3배, 기절 중 대상 +50%, 대기1 / 무게의 룬 기절 확률+10%→20%, 대기+1
- 수인: 야수의 난도질 0.6배×3, 타격마다 30% 출혈, 대기1 / 광폭 체력50% 이하 위력+15%→25%
- 바바리안: 분쇄 일격 1.6배, 자기 체력-8%, 대기2 / 전사의 함성 2턴 공격+2, 대가 다음 차례 방어-2

### 암살자
- 인간: 약점 찌르기 0.8배+고정4, 대기1 / 이어지는 칼끝 다음 공격 +10%→20%
- 엘프: 정령의 비수 1.0배+마법0.3배, 치명+10%, 대기1 / 바람 걸음 1턴 회피+10%→20%, 위력-10%
- 수인: 덮치기 0.5배×3(대상 50% 이하면 4회), 대기1 / 피 냄새 출혈 중 적에게 +10%→20%

### 무투가
- 인간: 발경 0.9배+고정4, 대기1 / 경락 타격 2턴 기절 저항 -20%→-30%, 대기+1
- 드워프: 강철 철권 1.5배 + 2턴 속도-2, 대기2 / 강철 피부 1턴 받는 피해 -5%→15%, 위력-10%
- 수인: 발톱 연격 0.4배×4, 대기1 / 야성의 리듬 3타 이상이면 마지막 타격 +15%→25%
- 바바리안: 메치기 1.3배 + 1턴 방어-3, 대기1 / 투혼 체력30% 이하 위력+20%→25%

### 궁수
- 인간: 다리 쏘기 0.9배 + 2턴 속도-3, 대기1 / 정밀 화살촉 고정+2→+4
- 엘프: 정령의 화살 1.0배+마법0.3배, 2턴 회피-10%, 대기1 / 바람의 인도 치명+10%→20%
- 수인: 추적 사격 1.1배, 출혈 대상 치명+20%, 대기1 / 사냥꾼의 표식 2턴 출혈 저항 -20%→-30%, 대기+1
- 바바리안: 강궁 관통 1.5배 + 방어 20% 무시, 대기2 / 위압의 화살 2턴 위축(공격-2), 위력-10%

### 사제
- 인간: 신성한 심판 신성0.8배+고정4, 대기1 / 수호의 축언 2턴 기절 저항 +20%→30%, 대기+1
- 엘프: 정령의 축복 회복 + 2턴 회피+10%, 대기1 / 생명의 숨결 다음 차례 시작 시 추가 회복 3→6, 대기+1
- 드워프: 화로의 룬 2턴 방어+3 + 소량 회복, 대기1 / 불씨의 룬 신성 공격 시 2턴 방어-2, 위력-10%
- 수인: 가시 덩굴 신성0.7배 + 2턴 둔화(속도-2), 대기1 / 독초의 축언 2턴 독 저항 -20%→-30%, 대기+1
- 바바리안: 선조의 토템 2턴 아군 전체 매 턴 체력2 회복, 대기2 / 선조의 힘 2턴 자기 공격+2, 대가 대기+1

### 마법사
- 인간: 마력 화살 0.7배+고정5, 대기1 / 비전 각인 2턴 받는 마법 피해 +10%→20%, 대기+1
- 엘프: 정령 폭풍 전체 0.5배 + 2턴 회피-10%, 대기2 / 정령 공명(원소 조각 없으면 위력+5%→10%, 있으면 원소 효과+10%→20%)
- 드워프: 용암 분출 1.2배 + 2턴 방어-2, 대기1 / 바위 각인 2턴 속도 -2→-4, 대기+1
- 드워프 특권: 불+흙 원소를 한 스킬에 동시 장착 가능
- 불 원소 = 위력 +10%

### 바드
- 인간: 행진곡 아군 전체 2턴 속도+2, 대기1 / 박자 맞추기 노래 받은 아군 다음 공격 고정+2→+4, 대기+1
- 엘프: 정령의 선율 회복 + 상태이상 1개 해제, 대기1 / 잔향 노래 중 매 턴 체력1→3, 대기+1
- 수인: 울부짖는 노래 적 전체 2턴 속도-2, 대기2 / 불안의 메아리 2턴 기절 저항 -15%→-25%, 대기+1
- 바바리안: 전쟁 북 아군 전체 2턴 공격+3·방어-1, 대기2 / 뿔피리 노래 시작 시 적 전체 1턴 공격 -1→-2, 대기+1
- 성장: 마법1 속도1 회피1

## 5. 디버프 (전부 지속 턴 + 저항 있음)
둔화(속도-) / 방어 감소 / 위축(공격-) / 기절(1턴 행동 불가, 걸릴 때마다 기절 저항 +40%, 몬스터 기본 저항) / 흔들림(기절 저항-) / 회피 감소 / 균열(받는 피해+) / 출혈 취약(출혈 저항-) / 중독(차례 끝 피해, 매 턴 30% 약화) / 중독 취약(독 저항-)

## 6. 작업 순서 제안
1. `data/fragments.ts`: Fragment 타입(id, job, race?, kind: main|sub, effects[], cost, maxLevel) + 위 데이터
2. `data/jobMatrix.ts`: 종족×직업 표, 용병 생성 시 사용
3. `game/skills.ts`: `validateSkill(merc, skill)` (부 조각 개수 동1/은+2, 종족 제한, 원소 중복 규칙), `resolveSkill(skill) → 합산 효과` (종류별 상한 clamp)
4. 전투 엔진: 디버프 타입 추가, 기절 저항 누적, 다회 타격, 방어 무시%, 고정 피해 처리
5. `previewAction`에 고정 피해·방어 무시·다회 타격 반영
6. Vitest: 상한 clamp, 부 조각 개수 검증, 불가 종족 조합 거부, 기절 저항 누적 테스트

## 질문 답변
1. 직업 목록
   - 수녀 → 사제(id `priest`). 이름만 바꾸고, 2차에서 성녀/성자 루트는 성별로 이름 표시 `{ female: "성녀", male: "성자" }`
   - 약초꾼, 정령술사는 삭제. 정령술사의 보호막은 가디언 부 조각 "수호막"으로 이동
   - 직업 id: knight, guardian, greatsword, assassin, monk, archer, priest, mage, minstrel(바드)
     → background의 `bard`와 겹치지 않게 직업은 `minstrel`, 표시 이름은 "바드"
2. 등급: 견습/숙련/노련/전설 → 동/은/금/미스릴/다이아/성휘 (각 3단계)
   - 기존 세이브는 변환하지 않고 초기화. 세이브에 `version` 필드를 두고, 버전이 다르면 새 게임으로 시작
3. 스킬 저장: `gen:` `combo:` `craft:` 문자열 체계는 전부 없애고 `{ main, subs }` 하나로 통일
   - 용병 생성 시 시작 스킬 = 자기 직업·종족이 쓸 수 있는 메인 조각 중 무작위 + 부 조각 0~1개 무작위
   - 기존 combo(종족×직업 조합 스킬)는 "종족 전용 조각"이 대신함
4. 기존 공통 조각(일격·강타·정령탄 등)은 폐기
   - 대기 시간 = 메인 조각의 기본 대기 + 부 조각 대가(대기 +1 등) 합. 위력 점수 합산 방식은 삭제

# 구현하면서 정한 것 (1단계, 2026-11-20) — 확인 필요

스펙에 수치·규칙이 없어서 임시로 정한 것들. 전부 data 파일에 있어서 바꾸기 쉽다.

- **대기 의미**: "대기 N" = 쓰고 나서 쉬는 자기 차례 수 (0이면 매 차례). 몬스터 스킬도 같은 뜻으로 바꿨다 (예전 수치 -1, 실제 동작은 그대로).
- **스탯 배율**: 스탯 보너스도 배율을 따른다 (힘 4인 용병의 1.4배 스킬 → +5.6). 예전에는 배율과 상관없이 +4였다. 혼합 피해 `scaling`과 같은 규칙.
- **등급 안 레벨업**: 3단계 → 2단계 → 1단계라 등급마다 레벨업 2번 (`LEVELS_PER_RANK = 2`, 경험치 5 / 8). 승급 자체는 스탯을 주지 않는다.
- **승급 비용**: 은 20 / 금 40 / 미스릴 70 / 다이아 110 / 성휘 160. 패시브 칸: 1 / 2 / 3 / 3 / 4 / 5.
- **보수·생존**: 등급별 보수 3 / 5 / 8 / 12 / 17 / 24, 생존 보정 0 / 3 / 6 / 9 / 12 / 15%.
- **시작 스킬**: 2개 (`START_SKILLS`), 스킬마다 50% 확률로 부 조각 1개.
- **해금·강화 비용**: 직업 조각은 직업 재료, 종족 조각은 종족 재료 (`JOB_MATERIAL`, `RACE_MATERIAL`). 강화 Lv2 금화 12 + 재료 2, Lv3 금화 25 + 재료 4.
- **상한 적용 범위**: 위력·방어 무시(25%), 치명(30%), 고정(15)만. 흡혈(투지 30%)은 조각 하나의 값이 이미 25%를 넘어서 상한에서 뺐다.
- **가디언 메인 대기**: 스펙에 없어서 수호 선언 2 / 감싸기 2 / 방패 강타 1 / 철벽 1 (철벽 방어 +3). 방패 강타 기절은 우선 30% 고정 (힘 비례는 2단계).
- **종족 공통 메인 대기**: 드워프 내려찍기 외에는 스펙에 없어서 0~2로 정했다.
- **맹독**: "중독 2턴 피해+2"를 턴당 피해 4로 읽었다.
- **몬스터 기본 기절 저항**: 일반 10% / 정예 25% / 층 보스 40% / 던전 보스 50%.
- **성별**: 성녀/성자 표시를 위해 모집 때 성별을 뽑아 AI 프로필에도 넘긴다.
- **샘플 용병**: 정령사 엘로웬 → 바드, 약초꾼 토브 → 무투가, 가디언 힐드를 새로 추가.
- **이벤트**: 수녀 → 사제, 약초꾼 "물 살피기" → 궁수, 약초꾼 "치료" → 사제, 정령사 → 엘프 종족.
- **장신구**: 사라진 직업 장신구를 가디언·무투가·바드에게 나눠 주고 두 개를 새로 만들었다 (직업마다 2개).
