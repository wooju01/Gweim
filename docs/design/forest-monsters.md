## 2. 새로 필요한 전투 기능 (우선순위 순)
1. 소환: 분열 슬라임(죽으면 작은 슬라임 2), 알 주머니(N턴 뒤 동굴 거미 부화, 그전에 부수면 안 함). 적 최대 수 제한
2. 도망: N턴 뒤 이탈(처치 보상 없음). 황금 숲 쥐: 희귀, 잡으면 금화 많이
3. 자폭: 자기 사망 + 광역 피해 (고블린 폭탄병)
4. 몬스터 지원 스킬: 고블린·오크 주술사(회복·강화), 오크 전투 군악병(전체 공격 강화)
5. 공격 시 상태이상: 독 슬라임·독거미·맹독 거미 → 중독 / 늑대 계열 → 출혈 / 산성 슬라임 → 방어 감소

# 구현하면서 정한 것 (2026-11-21) — 확인 필요
- **엔진 기능**: 몬스터 능력(`abilities`)에 `flee`(N번째 차례에 이탈), `explode`(N번째 차례에 자폭: 자신은 쓰러지고 모두에게 피해, 그전에 쓰러뜨리면 안 터짐)를 더했다. 스펙의 `traits.onDeath.explode`는 "죽으면 터짐"으로도 읽히는데, 막을 수 있는 시한폭탄 쪽이 전략적이라 차례 기반으로 했다.
- **대신 맞기**: 상태이상 `cover`(보호받음, 2턴). 건 유닛이 살아 있으면 그 유닛을 노린 단일 공격을 건 쪽이 대신 맞는다. 가디언 **감싸기**와 **타락한 세계수 근위병의 방패 막이**가 같은 규칙을 쓴다 (감싸기도 이제 실제로 동작한다).
- **정예**: 종 자체가 정예인 몬스터(★, `rank: "elite"`)와, 지역에서만 정예로 나오는 몬스터(홉고블린, 더 깊은 숲의 오크 광전사: 지역 몬스터 목록의 `elite: true`)를 나눴다.
- **데이터 형태**: 스펙의 `traits`·`drops` 대신 기존 구조를 이어 썼다 — 공격 시 상태이상은 `onHit`(몬스터당 하나), 분열·부화·도망·자폭은 `abilities`, 드롭은 `data/loot.ts`의 `DROPS`(새 몬스터는 비어 있음 = 드롭 없음). 기존 몬스터의 드롭은 대장간·전수관 재료라 지우지 않았다.
- **알 주머니**: 새끼 거미 둘 → 동굴 거미 하나 (스펙)
- **산성 슬라임**: 산성 분사 스킬(균열) → 공격 시 40% 방어 감소 (스펙)
- **황금 숲 쥐**: 출현 가중치 0.4 (1층 다른 몬스터 4~5), 두 번째 차례 도주, 회피 20%, 현상금 금화 25~40
- **보스 확률**: 거대 숲 멧돼지 0.2 (스펙). 거대 동굴 박쥐·오크 대장은 스펙에 없어 중간 층 기본 0.5
- **권장 등급**: 고블린 마을 동, 늪지대 동~은, 더 깊은 숲 은 (스펙대로 고침)
- **타락한 정령왕 호위**: 세계수 근위병 + 타락한 정령술사. 임시로 만들었던 히든 몬스터 3종(타락한 정령·가시 덩굴·포자 나무정령)과 "시드는 손길"(치유 감소)은 지웠다. 그래서 지금 치유 감소를 거는 몬스터는 없다.
- **몬스터 지원 AI**: 다친 아군이 없으면 회복 스킬을, 지켜 줄 동료가 없으면 방패 막이를 고르지 않는다. 방패 막이는 가장 다친 다른 동료에게.
- 모든 새 몬스터 수치는 초안이다.
