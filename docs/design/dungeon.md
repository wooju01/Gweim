# Ashen Company — 던전 시스템 업데이트 (2026-11-21 받음)

## 원칙
- 확률, 칸 수, 경험치 비율은 전부 data 파일 상수로 둔다(밸런스 때 조정).
- 몬스터와 보스 이름도 data에만 두고 코드에 하드코딩하지 않는다(이름이 바뀔 수 있음).

## 1. 던전 공통 규칙
- 층 칸 수: 무작위 범위. 층마다 `cells: { min, max }`
  - 기본 제안: 1층 7~10, 2층 9~12, 3층 이상 11~15
  - 히든 층은 개별 지정
- 층 마지막 칸 보스
  - `bossChance` 확률로 등장, 후보 2종 중 하나 무작위
  - 안 나오면 보물상자나 엘리트 칸으로 대체
  - 히든 층 보스는 확정 등장(`bossChance: 1`), 후보별 가중치 지원
- 경험치: 용병 등급과 던전 권장 등급의 차이로 배율
  - 같거나 낮음 1.0 / 한 등급 위 0.5 / 두 등급 위 0.1 / 세 등급 이상 0
  - 등급 순서: 동 < 은 < 금 < 미스릴 < 다이아 < 성휘 (등급 단위로 비교, 3단계는 무시)
- 후퇴
  - 맵 이동 중 후퇴: 패널티 없음, 전리품 유지, 마을로 귀환
  - 전투 중 후퇴: 용병 성격 태그로 호감 변화. 신중 계열 +, 호전·자존심 계열 -, 나머지 0. 대사는 AI가 생성

## 2. 던전 데이터 구조 (제안)
```ts
type FloorNode = {
  id: string; name: string; floor: number;
  recommendedGrade: Grade;            // 권장 등급(경험치 계산에 사용)
  cells: { min: number; max: number };
  boss?: { chance: number; pool: { monsterId: string; weight: number }[] };
  next: string[];                     // 다음 층 노드 id (비어 있으면 루트 끝)
  hidden?: { from: string; keyItem: KeyItemId; triggerChance: number }; // 히든 진입 조건
};
```

## 3. 미지의 숲 (동 던전)
```
1층 미지의 숲 (동3)
├─ 2층 깊은 숲 (동2) 보스: 나무 거인 → 드롭: 세계수의 가지, 빛나는 수액
│   ├─ 3층 고블린 마을 (동1~은3) 고블린 킹
│   ├─ 3층 늪지대 (동1) 슬라임 킹
│   └─ 3층 더 깊은 숲
│       ├─ 4층 오크 마을 (은3~은2) 오크 킹
│       └─ 4층 [히든] 타락한 엘프의 숲 (은2~은1, 12칸)
└─ 2층 미지의 동굴 (동2)
    ├─ 3층 거미 둥지 (동1~은3) 거미 여왕
    └─ 3층 늑대 굴 (동1) 우두머리 늑대
```
- 나무 거인: 느림, 단단함, 매 턴 회복. 패턴은 뿌리 묶기(속박), 가지 휩쓸기(전체 약한 피해), 껍질 굳히기(방어 상승)
- 히든 진입: 세계수의 가지 보유 + 3층 더 깊은 숲 사건 칸에서 확률 반응 → 사건에서 선택 → 4층이 타락한 엘프의 숲으로
- 타락한 엘프의 숲 보스(확정, 2종 중 하나)
  - 타락한 정령왕: 가시 덩굴 속박(아군 전체 둔화), 포자 폭발(광역 중독), 매 턴 회복
  - 타락한 엘프 여왕: 패턴 미정 → 일단 데이터 자리만 만들기
- 엘프 용병은 필수가 아님. 파티에 있으면 사건 대사와 선택지가 달라짐(AI 프롬프트에 종족 정보 전달)

## 4. 안개 늪 (은~금 던전)
```
1층 안개 낀 늪지 (은3) 늪지 히드라 / 진흙 두꺼비 군주
├─ 2층 잊혀진 공동묘지 (은2) 무덤지기 레버넌트 / 듀라한
│   ├─ 3층 시체 구덩이 [끝] 식인 구울 군주 / 살점 골렘
│   └─ 3층 뼈 동굴 해골 백부장 / 묘지기의 사냥개
│       └─ 4층 용의 무덤 [끝] 본 드래곤 / 해골 거인
└─ 2층 역병의 수도원 (은2) 고위 밴시 / 가고일 로드 → 핏빛 초대장 획득
    └─ 3층 오염된 예배당 역병 의사 / 이단 심문관
        ├─ 4층 금단의 대성당 [끝] 리치 / 네크로맨서 로드
        └─ 4층 [히든] 뱀파이어 성 (12~15칸)
```
- 3층 권장 은1~금3, 4층 금2~금1
- 뱀파이어 성 진입: 핏빛 초대장 보유 + 3층 오염된 예배당 사건에서 반응 → 선택
- 뱀파이어 성 보스(확정): 백작부인 weight 7(권장 금1) / 뱀파이어 로드 weight 3(권장 미스릴3)
- 보스가 뱀파이어 로드로 정해지면 보스 직전 칸에서 경고 이벤트
  - "불길한 기운" 문구 + 권장 등급 표시 + 용병 반응 대사(AI) + 맵 후퇴 선택지
  - 보스는 층 생성 시점에 미리 정해 두어야 함(경고를 띄우기 위해)

## 5. 히든 열쇠 아이템
- `KeyItemId`: `world_tree_branch`(세계수의 가지), `blood_invitation`(핏빛 초대장)
- 클랜 창고에 보관, 판을 넘어 유지, 종류마다 최대 1개
- 이미 가지고 있을 때 또 얻으면 금화나 재료로 변환
- 소모·유지 규칙: 히든 보스 처치 후 던전을 나옴 → 소모 / 맵 후퇴(경고 칸 포함), 전투 중 후퇴 → 유지 / 파티 전멸 → 잃음

## 6. 디버프 / 몬스터 특성
- 디버프 추가: `healReduction`(치유량 감소: 받는 회복량 -X%, 지속 턴, 저항)
- 침묵은 만들지 않음
- 몬스터 특성: `onHit: { status, chance }` 형식으로 공격 시 확률 부여 지원 (슬라임 중독, 거미, 늑대 등)
- 마법사 불 원소 수정: 위력 +10%(대가: 자기 체력 -5%)

## 나중에 (지금 구현 X)
- 재료 시스템(조각 해금·강화 재료)은 설계 보류 중
- 타락한 엘프 여왕 패턴, 보스별 상세 수치, 보스 출현 확률
- 엘프 마법사 + 타락한 정령왕 전용 대사 같은 종족·직업 연출

# 사용자 답변 (2026-11-21)
- 고용 의향: 중립(인사·질문)도 조금 오르게, 직접 쓴 말은 변화량 1.5배. 의심(suspicious)이 너무 잦다 → 밝은 분위기로. 대사는 따라갈 것처럼 말하는데 확률은 30%인 문제도 맞춘다.
- 안개 늪: 자리만 만들고 던전은 닫는다.
- 보스 후보: 스펙에 2종이 있을 때만 2종 중 하나, 1종이면 1종만.
- 히든 열쇠의 "판" = 원정 한 번 (원정이 끝나도 창고에 남고, 새 게임이면 사라진다).

# 구현하면서 정한 것 — 확인 필요
- **보스 확률**: 끝 지역 보스 1(확정, 예전처럼), 중간 층 보스(나무 거인, 안개 늪 중간 층) 0.5. `END_BOSS_CHANCE`, `MID_BOSS_CHANCE` (data/regions.ts)
- **보스가 안 나온 목적지**: 보물 1 : 정예 1. 정예 목적지는 정예 1마리 이상, 보물 목적지는 물자 2~3개 + 유물 1개 (data/dungeon.ts)
- **권장 등급 범위**("동1~은3")는 `[낮은 등급, 높은 등급]`으로 두고, 경험치 배율은 높은 쪽과 비교한다. 더 깊은 숲은 스펙에 없어서 동~은.
- **히든 사건 확률**: 열쇠가 있을 때 그 지역 사건 칸마다 50%, 층마다 한 번 (`HIDDEN_TRIGGER_CHANCE`)
- **히든 진입 시**: 스펙대로 다음 갈래가 히든 지역 하나로 바뀐다 (원래 갈래는 그 원정에서 못 간다)
- **나무 거인**: 체력 70, 방어 3, 속도 0, 매 차례 회복 4. 세계수의 가지 50%, 빛나는 수액 확정
- **타락한 엘프의 숲 일반 몬스터**: 스펙에 없어서 초안 3종(타락한 정령·가시 덩굴·포자 나무정령)을 만들었다. 타락한 정령왕 체력 120, 회복 5. 엘프 여왕은 데이터만 있고 가중치 0이라 아직 안 나온다.
- **열쇠 중복**: 세계수의 가지 금화 30, 핏빛 초대장 50
- **기존 층 보스**(배불뚝이 고블린, 고블린 명사수, 늑대 조련사, 홉고블린 대장)는 스펙 트리에 없어서 지금 나오는 곳이 없다. 데이터는 남겨 둠.
- **전투 후퇴 호감**: 기본 0. 신중(소심 +5, 편집증 +4, 냉소 +2), 호전·자존심(오만·무모 -5, 명예·허세 -4, 잔혹 -3), 나머지 0 (data/bond.ts)
- **슬라임 중독**: 초록 15%, 푸른 20%, 분열 15% (독 슬라임은 원래 50%)
- **치유 감소**: 기본 받는 회복 -50%, 2턴. 지금은 타락한 정령의 "시드는 손길"만 건다.
- **고용 의향**: 중립 = 호감 +2·의향 +5 (반복하면 줄어듦), 직접 입력은 오르는 쪽만 1.5배 (`NEUTRAL_GAIN`, `FREE_TEXT_MULTIPLIER` in game/merc/affinity.ts)
- **불 원소**: 이미 위력 +10% / 자기 체력 -5%라 바꾸지 않았다.
